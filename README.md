# Scoop bucket for Kiteline

[Kiteline](https://github.com/hon6/kiteline) is a phone remote for the coding agents already running on your computer: Claude Code, Codex, OpenCode and more, on your iPhone, iPad and Apple Watch.

```powershell
scoop bucket add kiteline https://github.com/hon6/scoop-kiteline
scoop install kiteline
```

The manifest is updated automatically with every release. Then get Kiteline on your iPhone from the [App Store](https://apps.apple.com/app/id6825244029) and scan the pairing code shown on your computer.
